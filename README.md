# BTCtelegramBot
A Telegram support bot that queries the bitcoin block explorer API

/start - Get started
/btc - show the latest bitcoin price from Coindesk and Luno

DEMO BOT: https://web.telegram.org/#/im?p=@TFCSupportBot

## Setup
1. `cp .env.example .env` and fill in your own values. **Never commit `.env`.**
2. `npm install && node app.js`

## Security note
An earlier bot token was exposed in this repo's git history and has been revoked.
If you fork this repo, create your own token with @BotFather.
